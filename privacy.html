"오늘 아침 증권 소식"(이하 "이 프로그램")은 운영자가 자신의 컴퓨터에서 실행하는 자동화 프로그램으로, 증시 브리핑 영상을 만들어 운영자 본인의 유튜브 채널에 올립니다. 이 방침은 이 프로그램이 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 접근하는 Google 데이터

이 프로그램은 YouTube Data API를 통해 다음 권한만 요청합니다.

  • youtube.upload: 운영자 채널에 영상 업로드
  • youtube / youtube.force-ssl: 업로드한 영상의 정보 수정, 재생목록 추가, 채널 확인

Gmail, 드라이브, 연락처 등 다른 Google 데이터에는 접근하지 않습니다.

2. 데이터 사용 목적

위 권한은 운영자 본인의 유튜브 채널에 브리핑 영상을 올리고 관리하는 데에만 사용합니다. 광고, 분석, 판매 등 다른 목적으로 사용하지 않습니다.

3. 데이터 저장

Google 로그인 후 받은 인증 토큰은 운영자 컴퓨터에만 저장되며, 외부 서버로 보내지 않습니다. 이 프로그램은 시청자나 다른 사용자의 개인정보를 수집하지 않습니다.

4. 데이터 공유

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않습니다. 영상 업로드를 위해 Google(YouTube)과 통신하는 것 외에는 어디에도 전송하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 프로그램이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

6. YouTube 서비스

이 프로그램은 YouTube API 서비스를 사용합니다. YouTube 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

7. 접근 권한 취소

언제든지 Google 계정 보안 설정의 서드 파티 연결에서 이 프로그램의 접근 권한을 취소할 수 있습니다. 취소하면 컴퓨터에 저장된 토큰은 더 이상 사용할 수 없으며, 운영자는 해당 토큰 파일을 삭제합니다.
